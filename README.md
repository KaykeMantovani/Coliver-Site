# Coliver — site

Site da **Coliver**, joalheria artesanal. Feito no Brasil. *O futuro é autoral.*

Protótipo de direção: loader com a estrela, hero com anel 3D (three.js), vitrine Drop 01 com pedido via WhatsApp e a seção "Do papel ao metal".

## Estrutura
- `index.html` — o site inteiro (HTML, CSS e JS num arquivo só)
- `assets/` — imagens (foto do grupo do WhatsApp, favicon)

## Rodar localmente
Abra o `index.html` no navegador. Não precisa instalar nada.

## Publicar
Funciona direto na Vercel, Netlify ou GitHub Pages (site estático, sem build).
